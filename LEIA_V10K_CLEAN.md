# DeckDeckDeco v10k-clean

O Ulanzi Studio agora mostra inspectors pequenos e limpos.

- Smart Button: so seletor de perfil + atualizar lista.
- Outras actions: so botao para abrir o painel web.
- O painel completo fica no navegador, via Control Panel.
- Smart Button nao vira READY/DONE/SAVED sozinho.
- Imagens estaticas do perfil sao enviadas em base64 para aparecerem na hora.

Instalar:

```powershell
npm run setup:windows
```

Depois abra o Ulanzi Studio de novo.

Pastas virtuais do deck

Use Smart Button em modo página com slotIndex 1, 2, 3... A página decide qual perfil aparece em cada slot.

Uso simples

  1. Crie perfis A, B, C no painel web.
  2. Arraste Smart Button para uma tecla do D200H.
  3. No painel pequeno do Ulanzi, escolha modo manual e perfil A, ou modo página e slotIndex.
  4. A tecla mostra a imagem/GIF do perfil. Ela só muda se a ação configurada mandar.

Para pasta virtual: crie um perfil com ação abrir pasta virtual/página e targetPage. Ao apertar, todos os Smart Buttons em modo página trocam conforme os slots daquela página.
